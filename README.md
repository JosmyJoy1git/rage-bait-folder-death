# Are You Really Sure? - Folder Deletion Utility

A clean, enterprise-styled web application designed to waste the user's time by asking an absurd, excessive number of bureaucratic confirmation questions before allowing folder deletion.

## 📌 Overview

**Are You Really Sure?** simulates a boring internal company IT utility (**Folder Deletion Utility**) designed with maximum administrative friction.

Features include:
- **Clean Enterprise Aesthetic**: Minimal, dark gray text, light gray backgrounds, muted corporate blue accent, restrained padding, standard buttons, no flashy landing page or fancy animations.
- **Interactive Target Folders**: Pre-populated mock folders (`College Project`, `Tax Documents 2021-2025`, `Super Secret Folder`, `Final_Final_v2_FINAL(1)`, `Memes (Do Not Open)`), search filtering, and custom folder creation.
- **16-Step Confirmation Wizard**:
  1. Primary intent check ("Are you sure you want to delete this folder?")
  2. Secondary verification ("Are you really sure?")
  3. Operational acknowledgment checkbox
  4. Mandatory reason categorization selector
  5. Psychological emotional attachment screening
  6. Retrospective sentiment audit
  7. Mandatory 10-second reflection countdown period
  8. Security verification phrase typing
  9. Cognitive sanity math check (`17 × 4 - 3 = 65`)
  10. Redundant 3-tier backup verification checkboxes
  11. Regret minimization assessment grid
  12. End-User Folder Destruction License Agreement (EUFDLA scroll-to-bottom agreement)
  13. Alternative compromise offers (e.g. rename folder to `Archive_Do_Not_Touch`)
  14. Safeguard Level 1 ("Are you double sure?")
  15. Safeguard Level 2 ("Are you triple sure?")
  16. Ultimate verification (type `DELETE` in ALL CAPS)
  17. Simulated deletion execution (dramatic 99% hanging pause)
  18. Official Deletion Certificate & Wasted Time Summary Report

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` directly in any standard web browser, or serve using any static web server:
   ```bash
   python -m http.server 8080
   ```
3. Open `http://localhost:8080` in your web browser.
